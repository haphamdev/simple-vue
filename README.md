# simple-vue

A test project for form validation with Zod and Vuetify.

## Custom validation composable

See [docs/form-validation-guide.md](docs/form-validation-guide.md) for how to apply validation on a form.

## VeeValidation

VeeValidation is also considered as an alternative approach. Please check out branch `using-vee-validate` to see more details.

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```

### Lint with [ESLint](https://eslint.org/)

```sh
npm run lint
```
